# Breast Ultrasound Feature Extraction and Classification

MATLAB-based analysis of breast ultrasound images for lesion feature extraction and benign/malignant classification.

## Topics
- Ultrasound image preprocessing
- Lesion masking and segmentation
- Connected-component analysis
- Lesion area measurement
- Aspect-ratio calculation
- Boundary irregularity analysis
- Mean intensity
- Intensity standard deviation
- Feature-set generation
- Machine-learning classification

## Classification Methods
- Support Vector Machine
- Random Forest
- Decision Tree
- Logistic Regression
